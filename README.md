## 개발자 필수 지침: 퍼블리싱 & 개발 협업 가이드

효율적인 프로젝트 진행을 위해 다음 지침을 반드시 숙지해 주세요!
이 지침은 상호 업무 효율을 극대화하고, 잠재적인 문제를 사전에 방지하기 위한 핵심 원칙입니다.

### 폴더 구조 및 역할 명확화

-   src 폴더는 퍼블리싱 개발을 위한 원본 템플릿 소스입니다. 모든 퍼블리싱 작업은 이 폴더를 기반으로 진행됩니다.
-   public 폴더에는 컴파일이 완료된 최종 HTML, CSS 파일이 위치합니다. 이는 배포를 위한 최종 결과물입니다.

### EJS 템플릿 언어 활용의 중요성

-   EJS는 Node.js 기반의 JavaScript 템플릿 언어로, 동적인 페이지 생성을 지원하는 핵심 퍼블리싱 도구입니다.
-   EJS 문법은 타임리프(Thymeleaf), JSP 등 다른 템플릿 언어와 유사하여 빠르게 적응할 수 있습니다.
-   public 폴더의 정적 파일을 참고하는 것도 가능하지만, 원활하고 효율적인 협업을 위해 EJS 원본 소스(src 폴더)를 기준으로 작업하시는 것을 권고합니다. 원본 소스를 통해 전체 구조와 로직을 파악하는 것이 훨씬 유리합니다.

### 퍼블리싱 소스코드의 독립성 유지 (매우 중요!)

퍼블리싱 소스코드들은 고유하게 보존되어야 하며, 개발 소스코드와 명확히 분리되어야 합니다.
이유는 소스코드 분리는 이슈 발생 시 문제의 원인을 신속하게 추적하고 해결하는 데 필수적입니다. 복잡하게 얽힌 코드는 디버깅 시간을 기하급수적으로 늘립니다.

### 퍼블리싱 이슈 발생 시 협업 프로세스

퍼블리싱 관련 이슈가 발생하면, CX팀에서 코드를 업데이트할 것입니다.
업데이트된 퍼블리싱 코드를 반드시 확인 후, 해당 변경사항을 여러분의 개발 코드에 정확히 반영해 주셔야 합니다.

## CSS 세미콜론

-   마지막 선언된 속성에도 세미콜론(;)을 사용한다.

## CSS 단위

-   모바일과 같이 유동적인 레이아웃 구현 시 상대단위(rem, %)를 사용한다.
-   1px과 text-indent:-9999em, border 단위는 예외로 한다.

-   z-index
    -   z-index값은 최소 10부터 시작하며 최고 9999이며 10 단위로 증감한다. 단, 중간에 변수가 생기면 예외로 1단위 값을 지정할 수 있다.
-   구분 단위 설명
    -   인라인 1 우선순위 1씩 증가, 기본요소 0
    -   그룹 10 우선순위 1씩 증가, 기본요소 10
    -   구조 100 우선순위 1씩 증가, 기본요소 100
    -   팝업 1000 우선순위 1씩 증가, 기본요소 1000

## 속성선언순서

-   밴더속성과 해당 속성은 해당 속성 뒤에 선언한다.
    -   예) .btn {border:1px solid #f60; \*border:2px solid #f60; border-radius:20x; -webkit-border-radius:2px}
-   !important 사용은 지양한다.
-   순서 구분 속성
    1. Layout display, visibility, overflow
    2. 위치 position, float, clear, z-index
    3. 크기/간격 width, height,
       margin, padding
    4. 모양/배경 border
       bakcground
    5. 폰트/정렬 font, color, text-align, vertcal-align
    6. 기타 언급되지 않는 속성들은 후순위로 적용한다.

## 공통규칙

-   naming은 영문 소문자, 숫자, 언더바(\_)로 작성한다.
-   단어조합시, [형태+의미+숫자+상태]의 형태로 작성한다.
-   숫자가 없으면 ‘1’이라는 숫자가 생략된 것으로 간주한다.
-   약속어를 기본으로 작성하나, 없으면 종류와 특성을 나타내도록 naming한다.
-   종류 구분 번호 예시
-   ID selector 카멜표기법
-   (camelCase) 한 자리수
-   (생략가능, 2, 3) errorMesage, controlCenter, controlCenter2
-   Class Selector 스네이크표기법
-   (snake_case) 한 자리수
-   (생략가능, 2, 3) tab_page, tbl_type1, tbl_type2
-   Image 스네이크표기법
-   (snake_case) 두 자리수
-   (01, 02, 03) btn_cancle01_off.gif
-   파일 및 폴더 스네이크표기법
-   (snake_case) cyber_center

## ID 선택자

-   id는 카멜표기법을 사용한다. 예)tabType1
-   최상위, 레이아웃, 폼 요소, 책갈피를 제외하고 id를 사용하지 않는다.
-   동일한 이름의 id는 문서에서 한번만 사용이 가능하다.

## CLASS 선택자

-   class는 언더바(*)방식을 사용한다. 예)tab*type1
-   다중의 클래스 지정을 허용하며 최대 3개 이상 사용하지 않도록 주의한다.
