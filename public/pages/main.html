Tech Overview

풍부한 경험과 전문성으로 바탕으로 고객의 요구사항을 정확하게 이해하고, 최적의 펌웨어 솔루션인 "All4Frame"을 제공합니다.

All4Frame 패키지별 특징

All4Frame-Core BASIC

  • DTO(DataTransterObject) 소스코드 자동생성
  • DTO 필드 마스킹 처리
  • DTO 필드 암호화 처리
  • Framework 표준 설정

All4Frame-WebMvc BASIC

  • 표준전문 구조에 따른 FixedLength, XML, JSON, Serial, Delimiter, gRPC 방식 서비스 통신 지원
  • 서비스 자동 등록
  • 서비스 단위 로깅
  • 표준화된 트랜잭션 제어

All4Frame-Rdbms BASIC

  • Repository 소스코드 자동생성
  • 멀티 데이터 소스 지원
  • 자동화된 SQL 로깅
  • 자동화된 SQL 타임아웃
  • 자동화된 최대 조회 Row 갯수 제어
  • 자동화된 SQL 페이징 처리
  • 자동화된 Auditing 처리 구조
    (createdBy, createAt, lastModifiedBy, lastModifiedAt)

All4Frame-Security BASIC

  • 다양한 유저 인증 방식지원 (Ldap, OAuth, DBMS)
  • 다양한 웹 취약점 해소 (CSRF, XSS, SSRF, SQL Injection)

All4Frame-Batch BASIC

  • Job Flow 디자인 기능
  • 대량 데이터 처리를 위한 Job 구현기능
  • StandAlone 기반 Job 실행
  • On-demand 기반 Job 실행

All4Frame-adminConsole
STANDARD

  • 프로젝트 멤버 권한 관리 기능
  • 통합 용어관리 기능
  • 전문 표준관리 기능
  • MQ(MessageQueue) 관리 기능
  • 배치 제어 관리 기능(스케줄러 포함)

Performance

TmaxSoft 엔지니어 경력보유자와 사업경험자를 다수 확보 유지하고 있으며,
지속적인 사업협력을 통한 핵심 Solution인 Framework 사업에 지속 참여하고 있습니다.
